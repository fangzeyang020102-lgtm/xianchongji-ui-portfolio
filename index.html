ABOUT THE PROJECT

为爱宠而设计，
也为每一个用心陪伴的人。

「贤宠集」是围绕宠物食品与日常生活构建的移动端商城 UI 设计项目，覆盖商品浏览、购物下单、订单售后、会员权益与宠物管理等场景。本展示基于已完成的设计界面整理，不涉及虚构的用户调研数据或上线成果。
